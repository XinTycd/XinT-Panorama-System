# 启动和后端性能对照

2026-11-14，Windows，Node.js 24.14.1。对照为本轮修改前的开发源码与优化后的源码。使用同一台机器、回环地址、隔离 SQLite 库和 10,000 条合成图库记录。测试已有 PSV 构建产物的启动，未计入首次安装与构建。

| 测量项 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 后端进程启动至监听，中位数 | 194 ms | 148 ms |
| 按编号读取单张全景图，中位数 | 15.06 ms | 0.28 ms |
| 按编号读取单张全景图，P95 | 19.51 ms | 0.38 ms |
| 小图片上传请求，中位数 | 58.29 ms | 2.59 ms |
| 单次上传响应体，中位数 | 5,420,979 字节 | 710 字节 |

每版交替启动 7 次，计时从 npm 进程创建到后端监听。编号查询预热 12 次后采样 50 次。上传使用原格式保存一张合成 PNG，每版测 8 次并排除首个样本。原接口响应包含完整图库，优化版控制台请求精简响应，并在一批图片保存后刷新一次图库。上传数据衡量的是单次接口和响应体，未包含批次末的图库刷新时间或大图转码时间。

嵌入页在配置返回前发出图片信息请求，并按配置加载 PSV 或兼容引擎。自动化测试覆盖两个引擎的资源选择及 HTTPS 媒体路径。资源体积按未压缩文件计算，默认 PSV 模式少请求约 645 KiB 的兼容引擎脚本。公网首屏时间与真实移动设备表现尚无本轮数据。
