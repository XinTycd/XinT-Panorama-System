# E02：项目诊断与发布验收

自动化覆盖由 `npm test` 执行，使用临时隔离存储。

## 回归场景

- 空项目诊断包含 `SCENES_EMPTY`，并且不允许发布；API 返回 422 和诊断报告。
- 有效项目生成带 SHA-256 快照，发布后可重新校验；修改快照内容会校验失败。
- 本地上传资源参与文件指纹；文件缺失、不可读或不是普通文件时报告失败，不让哈希异常变成 500。
- 远程资源诊断为外部依赖且不触发下载；验证结果标记为未核验，完整核验字段为 `false`。
- 多个场景引用同一远程资源时，诊断按资源 ID 去重统计。
- 默认场景之外无法由有效场景热点到达的场景显示 warning；单有任意一条跳转不代表全场景可达。
- 发布错误阻断、warning 可发布；创建并发发布时版本号不重复。

## 当前不覆盖

- 大文件批量哈希性能测试。
- 数字签名、密钥管理、审批与操作审计；这些能力尚未实现。
- 自动下载和核验远程图片；当前设计不会在诊断或发布时联网抓取资源。
