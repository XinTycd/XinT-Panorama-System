# 产品边界

## 产品定义

XinT Panorama 是以网站嵌入为核心的可自行部署 720° 全景查看器。宿主网站通过脚本或 iframe 展示图库中的全景图片；可选管理控制台用于管理图片、项目场景和热点，并预览和调试嵌入内容。后端默认在 7210 端口提供 API、widget 和静态查看器资源；控制台默认在 7211 端口运行。widget 显示单张全景图，不呈现整个项目或发布快照。

## 当前开源实现

- 元数据始终保存在本地 SQLite；图片新资源可选择当前浏览器 IndexedDB、本地服务端文件、本地 SQLite Base64 或 Turso 云端 SQLite Base64。客户端图片仅供同一浏览器来源读取，不能供 widget/发布页使用；SQLite/Turso 图片写入前可转码。
- 通过本地上传、图片链接或已有图片地址添加资源，后端分配唯一图库编号。
- 分组需要先创建再供资源选用；控制台提供分组、名称和编号筛选，每页显示 8 项，图标操作可编辑或删除资源记录。删除记录不删除媒体；删除已被场景引用的资源会被拒绝。
- 设置页可配置后端 API 地址、图片保存位置、保存格式、转码选项和预览引擎；图片/引擎设置仅允许从后端所在电脑的本地控制台修改。
- 使用项目 JSON 导入导出场景与热点配置；导出不包含图片文件，也不会导入发布历史。
- 控制台提供本地内置插件管理；项目工作区插件默认禁用，可通过“启用”和“禁用”按钮切换，状态保存在当前浏览器。启用后显示项目、场景与热点入口；不加载外部插件代码，也不提供远程权限开关。
- 提供标准全景查看器与 `embed.js`；默认使用 PSV，也可选择简化的原球面 renderer。PSV 使用自定义图标工具栏（PSV 原生 navbar 关闭）；legacy 仅支持拖动观察和缩放。查看器不显示罗盘、遥测、品牌、编号、分辨率或悬浮场景轨道 HUD。两者均不含多个投影模式或双图比较。
- 后端 API 提供项目诊断、发布快照和 SHA-256 校验，当前控制台没有对应的检查和发布操作入口。诊断错误阻止 API 创建发布快照，警告允许发布；远程资源与仅有元数据的资源显示为未核验。
- 当前发布版本为 [v0.2.3](./releases/v0.2.3.md)；该版本加入本地内置插件管理，并改进控制台与嵌入查看器的使用流程。

产品技术事实和边界以实现为准；运行条件与数据迁移见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

## 暂未实现的商业设想

本仓库当前不提供用户登录、组织隔离、RBAC、分享访问控制、审批、审计、签名发布、对象存储集成、SLA 或商业授权服务。

## 明确的产品限制

- 双图比较不属于当前能力；此前的比较实现不自动配准或计算图像差异。
- 发布快照包含元数据和资源清单，不等于自包含离线交付包；不包含被引用图片文件。
- SHA-256 可检测快照或本地文件变化，不提供签名身份、不可抵赖或来源认证。
- MySQL、公开分享页、外部插件安装、AI 配准和在线协作不属于当前实现。
