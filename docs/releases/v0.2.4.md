# XinT Panorama System v0.2.4

Release date: 2026-11-03

The console now loads only the configured panorama engine and requests gallery metadata alongside its configuration. Viewer scripts and styles can be served in precompressed Brotli form, and JSON API responses use compact serialization.

Supported local uploads can generate smaller WebP thumbnails while keeping the stored panorama as the viewer source. Embed scripts and iframes accept the compact toolbar preset. Scene details now show the image resolution without repeating its label.
