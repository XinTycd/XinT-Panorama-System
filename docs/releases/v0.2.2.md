# XinT Panorama System v0.2.2

Release date: 2026-08-15

This release improves panorama switching and viewer resource handling. Selecting another panorama no longer lets an older request replace the current image, and concurrent requests for the same image share a load. Temporary image URLs and viewer work are cleaned up when requests are cancelled or the viewer closes.

Rotation and view notifications now follow the viewer's render schedule. The drawing buffer is capped by device pixel ratio and container size to keep rendering work bounded.

The project overview now describes XinT Panorama as a self-hosted 720° panorama management and viewing system, with project scenes, hotspots, and embeddable previews.
