# XinT Panorama System v0.2.5

**发布日期：** 2026-11-11

## 主要更新

- **保护图库源文件。** 公开 API 响应不再返回媒体存储路径或源 URL。查看器和 API 使用移除元数据的无损预览及单独生成的 WebP 缩略图。预览保留解码像素与源尺寸；源文件无法安全解码或派生图不可用时，请求会失败，不会回退发送存储源文件。远程导入仅接受 HTTPS，校验 DNS 目标并在重定向时重新检查；原图代理已退役，返回 `410 Gone`。
- **控制台偏好保存到服务端。** API 地址、内置项目工作区插件状态、嵌入控件预设和工具栏可见状态保存在 `PANORAMA_STORAGE_DIR` 下的 `console-settings.json`。语言选择仍保存在当前浏览器。不会把旧浏览器偏好迁移到服务端；服务端尚无设置文件时使用默认值。
- **新增多语言控制台。** 控制台提供简体中文、繁体中文和英文界面，可在设置中切换语言。复制按钮提供成功反馈，“隐藏控件”表述更清晰，控制台滚动条也与界面主题统一。

## 升级说明

- 需要 Node.js 24 或更高版本，并使用 `npm ci` 安装依赖。
- `widget?imageUrl=...` 不再支持直接加载图片链接。请先将图片导入或注册到图库，再按图库编号嵌入。`/api/panoramas/proxy` 接口已退役。
- 升级前保存在浏览器中的控制台偏好不会复制到服务端设置文件。升级后请检查 API 地址、插件状态、嵌入预设和工具栏可见状态。语言选择仍按浏览器分别保存。
- 控制台设置接口仅接受回环客户端的同源请求，不开放 CORS。应用没有账号或角色系统；请避免将管理控制台和管理 API 暴露给公众访问。
- 已存媒体继续保留在所选存储后端。安全预览派生图由服务端生成和缓存，需要时可以重新生成。
