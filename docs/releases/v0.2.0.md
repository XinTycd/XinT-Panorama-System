# v0.2.0

**Release date: 2026-06-16**

This release updates the console and panorama processing workflow while retaining a simplified spherical viewer.

## Highlights

- Move gallery and project metadata to SQLite and add migration from legacy JSON gallery data.
- Add gallery groups and client-side filtering with eight items per page.
- Improve project, scene, hotspot, and gallery resource workflows.
- Add image storage choices for browser IndexedDB, local server files, local SQLite, and Turso SQLite, with supported JPEG, PNG, and WebP transcoding options.
- Add backup, restore, configuration validation, and a standalone embedding widget.
- Keep the viewer focused on standard spherical navigation with drag and zoom controls.

See [README](../../README.md), [API reference](../API.md), and [deployment guide](../../DEPLOYMENT.md) for details.
