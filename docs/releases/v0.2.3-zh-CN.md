# XinT Panorama System v0.2.3

发布日期：2026-09-19

本版本新增本地控制台插件注册表。项目工作区默认禁用，可在“插件”抽屉中启用或禁用；状态保存在当前浏览器，应用不会下载外部插件。

控制台可为选中的服务端全景图生成可复制的 iframe 和 JavaScript 代码，并提供完整、精简和无工具栏三种预设。嵌入查看器新增 frame 内的系统菜单，显示应用名称、版本和仓库链接。

本版本调整了项目和图库操作，包括按设置显示媒体选项，以及更可靠地刷新已删除场景。控制台和查看器共享 Phosphor 图标；嵌入页只加载选中的查看器引擎，本地图片写入和按编号查找也减少了重复工作。
