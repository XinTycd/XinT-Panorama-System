# XinT Panorama System v0.2.3

Release date: 2026-09-19

This release adds a local console plugin registry. The project workspace is disabled by default and can be enabled or disabled from the Plugins drawer. Its setting is stored in the current browser; the app does not download external plugins.

The console now produces copyable iframe and JavaScript snippets for a selected server panorama, with full, compact, and no-toolbar presets. The embedded viewer has a frame-local system menu with the app name, version, and repository link.

Project and gallery controls have been refined, including conditional media settings and safer scene deletion updates. Shared Phosphor icons are used in the console and viewer. Embeds load only the selected viewer engine, and local image writes and panorama lookup avoid unnecessary repeated work.
