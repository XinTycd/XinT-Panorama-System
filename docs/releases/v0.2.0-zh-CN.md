# v0.2.0

**发布日期：2026-06-16**

本版更新控制台和全景资源处理流程，并保留简化的球面查看器。

## 更新内容

- 将图库和项目元数据迁移到 SQLite，并支持从旧版 JSON 图库数据迁移。
- 增加图库分组，以及每页 8 项的客户端筛选分页。
- 改进项目、场景、热点与图库资源之间的管理流程。
- 增加浏览器 IndexedDB、本地服务端文件、本地 SQLite、Turso SQLite 四种图片保存位置，并支持 JPEG、PNG、WebP 转码选项。
- 提供备份、恢复、配置校验和独立嵌入 widget。
- 查看器聚焦于标准球面浏览，提供拖动和缩放控件。

详细信息见 [简体中文 README](../../README.zh-CN.md)、[API 参考](../API.md)和[部署指南](../../DEPLOYMENT.md)。
