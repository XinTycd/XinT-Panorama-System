# v0.2.1

**Release date: 2026-07-29**

This release adds a configurable viewer engine while keeping the existing gallery, project, scene, hotspot, and embed workflows.

## Highlights

- Use Photo Sphere Viewer 5.15.1 by default, with the simplified original spherical renderer available as a compatibility option. Only the selected engine runs at a time.
- Configure the engine in the local console or `config.json`; `PANORAMA_VIEWER_ENGINE` takes precedence over saved settings. Console switches recreate the viewer in place and preserve its current panorama and view.
- Build and serve the viewer assets locally from lockfile-pinned packages. No viewer code is fetched from a CDN. Docker images include generated assets.
- Provide a custom PSV toolbar with cookie-based visibility preferences. The compatibility renderer supports drag navigation and zoom controls only.
- Keep project scenes and hotspots working through the shared viewer interface, and use the global engine selection when a widget loads.
- Keep special projection modes and side-by-side comparison disabled.

## Validation scope

Desktop Chrome covered the console, both engines, widget, engine switching, panorama orientation and view mapping, toolbar preferences, and a 390px browser viewport. Eleven automated test groups and configuration checks passed. These checks do not represent testing on a physical phone or across browsers. Real Turso accounts, weak-network and long-run behavior, Docker runtime, tiled delivery, and large-image performance were not tested.
