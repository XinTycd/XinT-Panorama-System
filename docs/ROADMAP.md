# 开发路线图

路线图描述尚未完成的目标。下列项目不代表已经交付；版本顺序先夯实稳定性与兼容性，再扩展自动导览能力。

## 当前发布基线：0.2.5

已实现的基础：图库与自动编号、SQLite 单一存储、项目/场景/热点、JSON 项目导入导出、后端诊断与发布快照 API、图库和项目 API、查看器与嵌入、配置检查及备份恢复脚本。详细实现请看 [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md)。

## v0.3：稳定性与兼容性

目标：提高现有全景浏览、资源管理和网站嵌入在不同环境下的可靠性。

- 完善异常处理、数据保存与恢复，并加强关键流程的自动化回归测试。
- 验证不同浏览器、移动设备、屏幕尺寸与嵌入环境，修复兼容性问题。
- 验证弱网、大图、长时间运行及不同存储配置下的表现，针对实际问题优化。
- 明确项目数据与导入导出的跨版本兼容策略，补充升级和部署验证。
- 改进键盘操作和移动端交互；具体支持范围以实际测试结果为准。

## v0.4：全景镜头编排与自动导览

目标：通过关键帧编排全景视角，并在项目的多个场景之间连续播放。

- 捕获关键帧，记录所属场景、水平和垂直视角以及视野范围（缩放）。
- 提供关键帧排序、编辑、删除、移动时长和停留时间设置。
- 支持同一全景内平滑转动和缩放，以及播放、暂停、停止和循环。
- 支持项目内跨场景播放，评估预加载与淡入淡出等切换方式。
- 将编排数据随项目保存，并规划导入导出兼容性；评估在嵌入页面中播放。
- 首版范围、路线数量和兼容引擎支持方式待具体设计时确定。

跨场景过渡是图片之间的视觉衔接，不代表真实三维空间移动。

## 后续研究项

- 可视化场景编排、场景顺序、初始场景、热点编辑及独立项目浏览页。
- 空间记录与比较：同位置多批次记录、固定视角、图像配准、视角同步与差异标注。当前没有双图比较功能。
- 大图多分辨率切片及更快的媒体处理。
- 身份和项目权限、审核与审计、发布签名、对象存储接入、离线资源包、WebXR、BIM/资产系统连接器。

上述研究项需单独确认需求、范围和维护成本后再排期。

## 查看器现代化

查看器默认 PSV，并可在设置中选择简化原球面 renderer；一次只运行一个引擎，不做自动回退。两种引擎均只显示标准全景，暂不含多投影和双图比较。PSV 使用自定义图标栏（原生 navbar 关闭）；legacy 只显示缩放按钮。当前 viewer HUD 不含罗盘、遥测、品牌、编号、分辨率或悬浮场景轨道。桌面 Chrome 和 390px 响应式视口已检查；多分辨率切片、真实移动设备、其他浏览器、Turso、弱网长时运行、Docker 和 2K–16K 大图性能仍需后续独立验收，不作当前能力承诺。

当前场景热点与视角同步已保留并纳入 Chrome smoke 验收；更丰富的漫游导航仍需在后续阶段单独规划。PSV 迁移概要见[查看器现代化计划](./VIEWER_MODERNIZATION_PLAN.md)。
