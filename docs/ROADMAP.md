# 开发路线图

路线图描述尚未完成的目标。下列项目不代表已经交付；版本顺序按内容管理与漫游能力逐步扩展。

## 当前基线：包版本 0.2.1（2026-07-29）

已实现的基础：图库与自动编号、SQLite 单一存储、项目/场景/热点、JSON 项目导入导出、交付诊断与发布快照、图库和项目 API、查看器与嵌入、配置检查及备份恢复脚本。详细实现请看 [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md)。

## 内部阶段目标 Core 0.3：项目漫游体验

目标：让项目编辑和访客浏览流程更完整。

- 补齐可视化场景编排、场景顺序和初始场景管理。
- 完善热点编辑与漫游体验，改进移动端和键盘可访问性。
- 明确项目包兼容策略，并补充跨版本导入验收。
- 评估独立项目浏览页；当前没有独立分享页或访问授权能力。

## 内部阶段目标 Core 0.4：空间记录与比较

目标：将现有双图比较扩展为可管理的空间记录流程。

- 评估同位置多批次记录、固定视角保存和差异标注。
- 探索有序路线、巡检步骤及结果记录。
- 根据真实大图需求评估多分辨率切片和更快的媒体处理。

当前没有双图比较功能。未来若重新评估，需单独定义图像配准、视角同步和差异分析范围；不能将其视为已经完成的时间轴或变化检测。

## 后续研究项

身份和项目权限、审核与审计、发布签名、对象存储接入、离线资源包、WebXR、BIM/资产系统连接器，均需单独确认需求、安全边界和维护成本后再排期。

## 查看器现代化

查看器默认 PSV，并可在设置中选择简化原球面 renderer；一次只运行一个引擎，不做自动回退。两种引擎均只显示标准全景，暂不含多投影和双图比较。PSV 使用自定义图标栏（原生 navbar 关闭）；legacy 只显示缩放按钮。当前 viewer HUD 不含罗盘、遥测、品牌、编号、分辨率或悬浮场景轨道。桌面 Chrome 和 390px 响应式视口已检查；多分辨率切片、真实移动设备、其他浏览器、Turso、弱网长时运行、Docker 和 2K–16K 大图性能仍需后续独立验收，不作当前能力承诺。

当前场景热点与视角同步已保留并纳入 Chrome smoke 验收；更丰富的漫游导航仍需在后续阶段单独规划。PSV 迁移概要见[查看器现代化计划](./VIEWER_MODERNIZATION_PLAN.md)。
